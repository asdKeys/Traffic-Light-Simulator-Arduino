# [ARDUINO]Traffic Light Simulator

## About
A traffic light simulated with the Arduino!

## How to Run

Download the Arduino IDE, then copy and paste the code in the file "Traffic_Simuator_LED.ino" into the IDE.

### Building

### Parts Needed

- any Arduino board
- any breadboard
- 4 green LED's
- 4 red LED's
- 9 wires
